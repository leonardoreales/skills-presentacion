# Bitácora de presentaciones entregadas

Una entrada por presentación. Sirve para no repetir metáforas, saber qué funcionó con cada audiencia y reutilizar
lo que funcionó. Se escribe al cerrar la fase 7 y se completa después de la reunión con lo que dijo la audiencia.
Sin datos personales: roles, no nombres.

Plantilla de entrada:

```
## AAAA-MM-DD · Título
- Audiencia y reacción buscada:
- Arco (y si fue nuevo, su secuencia):
- Escenas: concepto elegido · mecanismos · descartados
- Identidad: perfil o derivada (paleta, tipografía)
- Entregado: ruta / URL del Artifact · videos
- Verificación: consola, 375 px, reduced-motion, vetados, cifras con fuente
- Qué funcionó con la audiencia:
- Qué no funcionó / qué cambiaría:
```
